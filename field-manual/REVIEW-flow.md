## 1. Flow Bugs
- **Stale `stage.json` on Analyze & Stop** [PROVEN]: `POST /api/analyze` ([display.py:164-177](display.py)) neither clears `live/stage.json` nor sets `first=True` ([inspect_mode.py:257](inspect_mode.py)), so the UI displays the previous verdict/frame during load and inference. `stop_all()` ([display.py:122-129](display.py)) also leaves stale `stage.json`.
- **Demo picker overwritten by 500 ms poll** [PROVEN]: `#pick.onchange` ([display.py:393](display.py)) updates `#img`/`#cap`, then `poll()` ([display.py:420-421](display.py)) overwrites `#cap` (and `#img` if `S.frame` is set) within 0.5 s ([display.py:407,411](display.py)).
- **`error` stage blanks `#status`; other crashes freeze UI** [PROVEN]: `stage='error'` ([inspect_mode.py:180](inspect_mode.py)) omits `verdict`, so `#status` renders blank ([display.py:404-405](display.py)); other failures ([inspect_mode.py:60,83,163](inspect_mode.py)) exit without writing `error`, freezing the prior stage.
- **`UNSURE` styled as red `BAD` + wrong empty-text fallback** [PROVEN]: [display.py:404,406-408](display.py) styles `UNSURE` as `.bad` (`Anomaly (box): UNSURE`) instead of `.warn`. If `explain()` returns empty `sent`, [inspect_mode.py:230](inspect_mode.py) emits `"UNSURE: matches the reference"`.
- **`mock_feed.sh` exits immediately, desyncing `running()`** [PROVEN]: [mock_feed.sh:11-20](mock_feed.sh) backgrounds `(...) &` and exits, so `PROCS['feed'].poll()` ([display.py:105](display.py)) is immediately non-None; if `loop` crashes, `running()` becomes `[]` while the feed subshell keeps overwriting `live/latest.jpg`.

## 2. Process Lifecycle & Smallest Fix
- **Stop kills `zetic_d1_cli` mid-load** [PROVEN]: `D1.__init__` ([inspect_mode.py:70-72](inspect_mode.py)) stays in `inspect_mode.py`'s process group. `stop_all()` sends `os.killpg(..., SIGTERM)` ([display.py:127](display.py)), killing `zetic_d1_cli` directly (even mid-load), while [inspect_mode.py:265-270](inspect_mode.py) lacks a `SIGTERM` handler and never `wait()`s on `_d1.p`.
- **`display.py` shutdown orphans workers** [PROVEN]: `spawn()` sets `start_new_session=True` ([display.py:109](display.py)), and [display.py:434-437](display.py) has no `finally: stop_all()` or `SIGTERM` handler. Restarting `display.py` orphans `d1`/feed (`PROCS` is in-memory only) [PROVEN], risking duplicate NPU `D1` loads or mid-load kills [INFERRED].
- **Smallest fix**: Add `start_new_session=True` to `D1` `Popen` ([inspect_mode.py:70](inspect_mode.py)); trap `SIGTERM` in `inspect_mode.py:256` to set a stop flag checked around `check_once()` and call `_d1.p.wait(timeout=10)` in `finally:`; wrap `serve_forever()` in `finally: stop_all()` ([display.py:434-437](display.py)) plus a `SIGTERM` handler.
